Arrow Function Examples

This page shows the same function written three different ways: as a named function, a function expression, and an arrow function. The example was inspired by the arrow function slides from class. The function converts a string into uppercase text.

Named Function

function makeUpperCase(aString) {
    return aString.toUpperCase();
}

console.log(makeUpperCase("here is a string"));

Function Expression

const makeUpperCaseExpression = function(aString) {
    return aString.toUpperCase();
}

console.log(makeUpperCaseExpression("here is a string"));

Arrow Function

const makeUpperCaseArrow = aString => 
    aString.toUpperCase();

console.log(makeUpperCaseArrow("here is a string"));
